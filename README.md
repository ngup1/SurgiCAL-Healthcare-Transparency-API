# SurgiCAL API

A FastAPI service for comparing **surgical procedure prices, hospital and surgeon quality, and medical-device safety** in California. It runs on PostgreSQL with PostGIS for distance search and pg_trgm for fuzzy text search.

> **All data in this repository is fictional.** Hospitals, providers, manufacturers, devices, prices and quality scores are generated by `api/seed/generate.py`. CPT code numbers are real; their descriptions are paraphrased.

[![API CI](https://github.com/ngup1/surgical-api/actions/workflows/api-ci.yml/badge.svg)](https://github.com/ngup1/surgical-api/actions/workflows/api-ci.yml)

## Quick start

Requires Docker.

```bash
make up          # builds and starts Postgres/PostGIS (seeded) + the API
open http://localhost:8000/docs
```

Swagger UI at `/docs` lets you try every endpoint. Some values to try:

| Try | Example |
|---|---|
| Hospital | `GET /hospitals/050801` |
| Knee replacement prices, cheapest first | `GET /prices?cpt=27447` |
| Search across procedures, providers, hospitals and devices | `GET /search?q=knee` |
| Device recalls and adverse events | `GET /devices/68670191-dbe2-5dbd-a693-5f7118cab2c2` |

Stop with `make down`. Reset the database to the seed data with `make db-reset`.

## Endpoints

| Area | Endpoints |
|---|---|
| Hospitals | `GET /hospitals`, `/hospitals/{ccn}`, `/hospitals/{ccn}/providers` |
| Providers | `GET /providers`, `/providers/{npi}` |
| Prices | `GET /prices`, `/prices/compare` |
| Devices | `GET /devices`, `/devices/by-procedure/{cpt}`, `/devices/{id}`, `/devices/{id}/recalls`, `/devices/{id}/adverse-events` |
| Search | `GET /search` |
| Health | `GET /health` |

Malformed input returns `422` with the bad field named:

```json
{
  "code": "validation_error",
  "detail": "Invalid value for 'npi': Must be a 10-digit National Provider Identifier, e.g. 1572628497",
  "errors": [{ "field": "npi", "location": "path", "message": "...", "input": "123" }]
}
```

[`api/API_GUIDE.md`](api/API_GUIDE.md) explains the API's design and how it uses FastAPI.

## Development

```bash
make install-dev   # virtualenv + API, test and lint dependencies
make db-up         # database only, on localhost:5433
cp api/.env.example api/.env
make run-api       # API with auto-reload on localhost:8000

make test          # pytest against the seeded database
make lint          # ruff check + format check (make format to fix)
make seed-data     # regenerate the mock data, then make db-reset
```

## CI/CD

[`.github/workflows/api-ci.yml`](.github/workflows/api-ci.yml):

- **Every push and pull request:** ruff lint, then the test suite against a seeded PostGIS database, then the production image is built and smoke-tested.
- **Merges to `main`:** the image is published to `ghcr.io/ngup1/surgical-api` for amd64 and arm64, tagged `sha-<commit>` and `latest`.

## Project layout

```
api/
  main.py, routers/      FastAPI app and endpoints
  validation.py          shared input formats; exceptions.py: 422 error format
  tests/                 pytest suite
  seed/                  mock-data generator, JSON fixtures, seed.sql
  db/Dockerfile          PostGIS image with migrations + seed data
  Dockerfile             production API image
migrations/              database schema (SQL)
etl/                     pipeline that loaded real CMS/FDA data (not needed for the mock setup)
```
